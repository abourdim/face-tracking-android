# 👁️ Face Tracking Kids — Android wrapper

Capacitor wrapper that packages the [face-tracking](https://github.com/abourdim/face-tracking) web app as an installable **Android APK**.

> تتبع الوجه للأطفال · Face Tracking Kids

A kid-friendly face tracking app that uses your camera to detect smiles, blinks, and head movement in real time. Built for classrooms and workshops with optional micro:bit Bluetooth integration. No accounts, no installs — just open and play.

## Quick start

```bash
./manage.sh    # auto-detects your OS, then opens the menu
```

Build, test on emulator, and prepare a Play Store release from a single guided menu. See [WORKSHOP.html](WORKSHOP.html) for the full step-by-step guide.

## Download the latest APK

[📦 v1.0-debug release](https://github.com/abourdim/face-tracking-android/releases/latest) · [![QR](releases/download-qr.svg)](https://github.com/abourdim/face-tracking-android/releases/latest)

Scan the QR with an Android phone, or `adb install -r face-tracking-v1.0-debug.apk`.

## Capabilities required at runtime

- Camera + microphone (`getUserMedia`, runtime permission)
